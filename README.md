# قالب دعوة الزفاف الملكي البحري المتكامل (Royal Ocean Wedding Invitation Platform)

قالب قياسي فاخر واستثنائي لمواقع دعوات الزفاف، مصمم بتأثيرات الزجاج البلوري (Frosted Glassmorphism) ولمسات الذهب الملكي ليتناغم كلياً مع مشهد أمواج البحر الحية، ومزود بنظام إدارة مدعوين ولوحة تحكم احترافية متكاملة.

---

## 🌟 أبرز مميزات المشروع

1. **خلفية الفيديو الحي والمحرك الصوتي**:
   - خلفية أمواج البحر الطبيعية الحية تعمل بانسيابية وتتكيف مع مختلف الشاشات.
   - زر تحكم عائم ذكي بالصوت مع مؤثر مرئي لمسارات وموجات الصوت (Equalizer Visualizer).

2. **المونوغرام الملكي والألقاب الشرفية**:
   - مونوغرام دائري مذهب ومتحرك يحمل الحرفين "M & H" و "م & ح".
   - صياغة شرفية رفيعة المستوى لدعوة العائلتين الكريمتين مع آية قرآنية كريمة بالخط العربي الأصيل.
   - أسماء العروسين "محمد وحنين" بتدرج الذهب الخالص وتوهج لطيف.

3. **العداد التنازلي الثلاثي**:
   - ثلاث بطاقات مذهبة تعرض الوقت المتبقي بالأيام، الساعات، والدقائق، مصحوبة بوميض الثواني الحي.

4. **مسار برنامج ومراسم الحفل**:
   - خط زمني تفاعلي مضيء يوضح فقرات الحفل بالتوقيت والأيقونات المعبرة (استقبال الضيوف، الزفة الملكية، تبادل الخواتم، مأدبة العشاء، الصور التذكارية).

5. **معرض صور الذكريات (Overlapping Zig-Zag Layout)**:
   - تخطيط متعرج ومتداخل للصور مع بطاقات وصفية رومانسية تطفو فوق الصور بظلال ناعمة.
   - دعم تكبير الصور الفوري (Lightbox Modal) بجودة فائقة.
   - خيار إظهار أو إخفاء المعرض للحفاظ على سرعة وسلاسة التصفح.

6. **الموقع الجغرافي والتقويم الذكي**:
   - تفاصيل القاعة والعنوان (اللاذقية، سوريا).
   - زر توجيه فوري عبر خرائط جوجل (Google Maps).
   - زر إضافة الموعد إلى تقويم الهاتف (Google Calendar و Apple iCal عبر ملف `.ics`).
   - زر مشاركة رابط الدعوة عبر واتساب وتطبيقات التواصل.

7. **تأكيد الحضور وحائط الأمنيات (RSVP & Wall of Wishes)**:
   - نموذج تفاعلي لتسجيل الاسم، الهاتف، حالة الحضور، عدد المرافقين، وكلمة طيبة للعروسين.
   - مؤثرات احتفالية (Confetti & Sparkles) مبهجة فور إرسال الرد.
   - خيار إرسال تأكيد الحضور مباشرة عبر تطبيق واتساب (WhatsApp) برسالة مجهزة ومنسقة تلقائياً.
   - حائط أمنيات حي يعرض مباركات الضيوف فورياً على الصفحة.

8. **لوحة التحكم الإدارية الاحترافية (Admin Dashboard)**:
   - مسار مستقل ومحمي برمز مرور سري (PIN: `1234`) عبر الرابط `#admin`.
   - لوحة مفاتيح رقمية أنيقة تدعم الإدخال باللمس ولوحة المفاتيح.
   - 4 بطاقات مؤشرات أداء رقمية (KPI Metrics): إجمالي الردود، نسبة التأكيد، نسبة الاعتذار، وإجمالي الحضور الفعلي المتوقع شاملاً المرافقين.
   - جدول بيانات تفاعلي يدعم البحث اللحظي، الفلترة حسب الحالة، تعديل الحالة، وحذف أي سجل.
   - زر **تصدير كشف الحضور إلى ملف Excel (CSV)** يدعم اللغة العربية تماماً بترميز UTF-8 مع BOM.
   - ميزة طباعة كشف الحضور الورقي المنظم.
   - تبويب إدارة ومراجعة حائط التهاني.
   - محرر إعدادات وتفاصيل المناسبة والرمز السري.

## 🚀 طريقة التشغيل محلياً

المشروع مصمم ليعمل دون الحاجة لأي أدوات بناء معقدة (Zero-build overhead). يمكن تشغيله عبر أي خادم ويب محلي:

```bash
# باستخدام بايثون:
python -m http.server 8080

# أو باستخدام Node.js:
npx serve .
```

ثم افتح المتصفح على:
- رابط بطاقة الدعوة: `http://localhost:8080/`
- رابط لوحة التحكم: `http://localhost:8080/#admin` (رمز المرور الافتراضي: `1234`)
